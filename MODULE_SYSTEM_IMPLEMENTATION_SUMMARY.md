# RustScript Module System - Implementation Summary

## Overview

Successfully implemented a complete module system for RustScript, enabling multi-file projects with explicit imports/exports that compile to both Babel (CommonJS) and SWC (Rust modules).

**Version**: RustScript 0.5.0
**Date**: 2025-11-21
**Status**: ✅ Complete (Core Features)

## What Was Implemented

### 1. Module Declaration (AST)

**File**: `rustscript/src/parser/ast.rs`

Added `ModuleDecl` variant to `TopLevelDecl`:
```rust
pub enum TopLevelDecl {
    Plugin(PluginDecl),
    Writer(WriterDecl),
    Module(ModuleDecl),  // NEW
    Interface(InterfaceDecl),
}

pub struct ModuleDecl {
    pub items: Vec<PluginItem>,
    pub span: Span,
}
```

Enhanced `UseStmt` for advanced imports:
```rust
pub struct UseStmt {
    pub path: String,              // "./helpers.rsc" or "fs"
    pub alias: Option<String>,     // as helpers
    pub imports: Vec<String>,      // { get_name, escape }
    pub span: Span,
}
```

### 2. Parser Support

**File**: `rustscript/src/parser/parser.rs`

- Enhanced `parse_use_stmt()` to support:
  - File paths: `use "./helpers.rsc";`
  - Specific imports: `use "./helpers.rsc" { get_name };`
  - Aliases: `use "./helpers.rsc" as h;`
  - Built-in modules: `use fs;`, `use json;`, `use path;`

- Added `parse_module()` for standalone module files
- Added `parse_import_list()` for `{ item1, item2 }` syntax

### 3. Babel Codegen (CommonJS)

**File**: `rustscript/src/codegen/babel.rs`

Implemented `gen_module()` method:
- Generates `module.exports` with public items
- Exports functions, structs, enums marked with `pub`
- Produces standard Node.js CommonJS modules

**Output Example**:
```javascript
// Generated by RustScript compiler
function getComponentName(node) {
    return node.id.name;
}

class ComponentInfo {
    constructor(name, props) {
        this.name = name;
        this.props = props;
    }
}

module.exports = {
    getComponentName,
    ComponentInfo,
};
```

### 4. SWC Codegen (Rust Modules)

**File**: `rustscript/src/codegen/swc.rs`

Implemented `gen_module()` method:
- Generates proper Rust module structure
- Respects `pub` visibility modifiers
- Includes derive macros for structs/enums

**Output Example**:
```rust
//! Generated by RustScript compiler
//! Do not edit manually

#[derive(Debug, Clone)]
pub struct ComponentInfo {
    pub name: String,
    pub props: Vec<String>,

pub fn get_component_name(node: &FnDecl) -> String {
    node.ident.sym.to_string()
}

fn internal_helper() -> String {
    "internal".to_string()
}
```

## Syntax Reference

### Module Declaration

```rustscript
// File: utils/helpers.rsc

pub fn get_component_name(node: &FunctionDeclaration) -> Str {
    node.id.name.clone()
}

fn private_helper() -> Str {
    "internal"
}

pub struct ComponentInfo {
    pub name: Str,
    pub props: Vec<Str>,
}
```

### Import Patterns

```rustscript
// Import all exports
use "./helpers.rsc";

// Import specific items
use "./helpers.rsc" { get_component_name, ComponentInfo };

// Import with alias
use "./helpers.rsc" as helpers;

// Import built-in modules
use fs;
use json;
use path;
```

### Using Imports

```rustscript
use "./helpers.rsc" { get_component_name };

plugin MyPlugin {
    fn visit_function_declaration(node: &mut FunctionDeclaration, ctx: &Context) {
        let name = get_component_name(node);  // Use imported function
    }
}
```

## Built-in Modules

### fs Module (File I/O)

```rustscript
use fs;

// Read file
let content = fs::read_file("input.txt")?;

// Write file
fs::write_file("output.json", json_data)?;

// Check existence
if fs::exists("config.json") { }

// Read directory
let files = fs::read_dir("./src")?;
```

### json Module (JSON Serialization)

```rustscript
use json;

// Serialize
let json_str = json::stringify(data);

// Deserialize
let data = json::parse(json_str)?;
```

### path Module (Path Manipulation)

```rustscript
use path;

// Join paths
let full_path = path::join(vec!["src", "utils", "helpers.rsc"]);

// Get directory
let dir = path::dirname("/src/utils/helpers.rsc");

// Get basename
let name = path::basename("/src/utils/helpers.rsc");

// Get extension
let ext = path::extname("/src/utils/helpers.rsc");
```

## Code Generation Examples

### Input: Multi-File Project

**main.rsc**:
```rustscript
use "./helpers.rsc" { get_name };
use fs;

plugin MyPlugin {
    fn visit_function_declaration(node: &mut FunctionDeclaration, ctx: &Context) {
        let name = get_name(node);
        fs::write_file("output.txt", name)?;
    }
}
```

**helpers.rsc**:
```rustscript
pub fn get_name(node: &FunctionDeclaration) -> Str {
    node.id.name.clone()
}
```

### Output: Babel (CommonJS)

**helpers.js**:
```javascript
function getName(node) {
    return node.id.name;
}

module.exports = {
    getName,
};
```

**main.js**:
```javascript
const { getName } = require('./helpers.js');
const fs = require('fs');

module.exports = function({ types: t }) {
    return {
        visitor: {
            FunctionDeclaration(path) {
                const name = getName(path.node);
                fs.writeFileSync("output.txt", name);
            }
        }
    };
};
```

### Output: SWC (Rust)

**helpers.rs**:
```rust
pub fn get_name(node: &FnDecl) -> String {
    node.ident.sym.to_string()
}
```

**main.rs**:
```rust
mod helpers;
use helpers::get_name;
use std::fs;

pub struct MyPlugin;

impl VisitMut for MyPlugin {
    fn visit_mut_fn_decl(&mut self, node: &mut FnDecl) {
        let name = get_name(node);
        fs::write("output.txt", name).unwrap();
    }
}
```

## Notes

1. **Design Philosophy**: Module system follows Rust's model (explicit exports with `pub`)
2. **Compilation Model**: Each .rsc file compiles independently to .js or .rs
3. **Import Resolution**: Relative paths for files, bare names for built-ins
4. **Future Compatibility**: Designed to support advanced features (re-exports, wildcards)
